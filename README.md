This is a pre-alpha build of a Tournament bracket seeder, and simulation application. Currently, JDBC is located in the "jdbc" branch of this repository, until extensive testing with data persistence is completed.
The main branch of this project can correctly seed and simulate a full bracket without data persistence. The game names are hardcoded for Street Fighter 6, so please use the game name "Street Fighter 6"
for testing.
